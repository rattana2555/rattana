อัตราค่าธรรมเนียมที่แอพถอดได้จากชีท

คำนวณย้อนกลับจากข้อมูลจริง
แอพไม่ได้เชื่อ % ที่เขียนในหัวคอลัมน์ แต่ถอดอัตราจริงจากตัวเลขในชีท (บางหัวคอลัมน์เป็นค่าเก่า) แก้ได้ทุกช่อง ทั้งประเภท (% / บาทคงที่ / ไม่คิด) และตัวเลข กด "บันทึก" แล้วกำไรกับ Margin ทั้งแอพจะคำนวณใหม่ทันที และจำค่าไว้ในเครื่องนี้
ยังไม่เขียนกลับเข้าชีท — คอลัมน์ค่าธรรมเนียมในชีทเป็นสูตร ถ้าแอพเขียนตัวเลขทับลงไป สูตรของแถวนั้นจะหายถาวร แอพเลยเขียนกลับแค่ 2 คอลัมน์เดิม (ช่อง A และ ราคาตั้ง) เท่านั้น
ถ้าอยากให้แก้อัตราในชีทได้ด้วย ผมต้องเห็นสูตรจริงก่อนว่าเขียนไว้แบบไหน แล้วจะทำให้แก้เฉพาะตัวเลขอัตราในสูตรได้

เลือกเงื่อนไขแล้วกด "ดูตัวอย่าง"

บันทึกการเปลี่ยนแปลง

ติดตั้ง Apps Script (ทำครั้งเดียว)

  1. เปิด Google Sheet → เมนู ส่วนขยาย (Extensions) → Apps Script
  2. ลบโค้ดเดิมที่มีอยู่ทั้งหมด แล้ววางโค้ดด้านล่างลงไป
  3. แก้บรรทัด TOKEN เป็นรหัสลับของคุณเอง แล้วกรอกรหัสเดียวกันในหน้าตั้งค่า — ห้ามใช้ค่าตัวอย่าง เพราะแอพเปิดสาธารณะ ใครก็อ่านโค้ดนี้ได้
  4. กด Deploy → New deployment → เลือก type Web app
  5. ตั้ง Execute as: Me และ Who has access: Anyone → กด Deploy
  6. อนุญาตสิทธิ์ (Authorize) → คัดลอก Web app URL มาวางในหน้าตั้งค่า
แอพเขียนลงชีทแค่ 2 คอลัมน์เท่านั้น คือ ช่อง A (ติ๊ก) และ ราคาตั้ง — คอลัมน์สูตรอื่น ๆ (ค่าธรรมเนียม กำไร Margin) ชีทจะคำนวณเองตามปกติ ไม่ถูกแตะต้อง
